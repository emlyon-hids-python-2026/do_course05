# do_course05

Reference project for course 05: it prints "Hello, world!" and shows the expected structure of a student project (uv, git, VSCode).

## Installation

```bash
git clone git@github.com:emlyon-hids-python-2026/do_course05.git
cd do_course05
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
